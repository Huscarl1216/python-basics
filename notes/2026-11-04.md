## 새 개념
- 리스트(list): `[ ]`, 요소(element), 인덱스(index)는 `0` 부터 시작, `-1` 은 마지막, `len()`
- 반복문(for): `for word in words:`, 콜론 `:`, 들여쓰기(indentation)로 반복의 안과 밖 구분
- f-string: `f"{변수}"`, `{ }` 안에 식(expression) 넣기. `print()` 에 쉼표를 쓰면 공백이 자동으로 들어가는 것과의 차이
- `len()` 은 문자열(string)에도 사용 가능: `len("하늘")` → `2`
- PEP 8: 쉼표 뒤 공백, snake_case 변수 이름, 복수형 리스트와 단수형 반복 변수, 여러 줄 리스트 세로 맞춤
- Git: `add` → `status` → `commit -m` → `push` → `log --oneline -3`
  - `HEAD` 와 `origin/main` 읽는 법
  - 좋은 커밋 메시지는 파일 이름보다 내용을 담음
- `.gitignore`: 폴더 패턴 `/`, 와일드카드(wildcard) `*`, 주석 `#`
  - 틀려도 오류가 나지 않으므로 직접 검증해야 함

  - 해결: f-string 으로 변경
- 변수 이름 `Kwords`

  - 해결: `korean_words` 로 변경
- `.gitignore` 의 `__pychche__/` 오타

  - 해결: `__pycache__/` 로 수정하고 검증
