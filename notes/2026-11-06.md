## 새 개념
- `if 조건:` → 조건이 참(True)일 때만 들여쓴 줄 실행
- `else:` → 조건이 거짓(False)일 때 실행
- `elif 조건:` → 위에서부터 차례로 검사하고, 처음 참인 것 하나만 실행
- 비교 연산자(comparison operator): `==` 같다, `!=` 다르다, `>=` 크거나 같다, `<=` 작거나 같다
  - 결과는 항상 `True` 또는 `False` (불리언, boolean)
- `and` → 둘 다 참이어야 참, `or` → 하나만 참이어도 참
- for 안에 if를 넣으면 "반복하면서 조건에 맞는 것만 고르기"가 됨
- 연쇄 비교(chained comparison): `2 <= len(word) <= 3` 은 `and` 로 묶은 두 조건과 같은 뜻
